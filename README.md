# Web Automation Testing – QA Portfolio

Este repositorio forma parte de mi portafolio profesional como QA, enfocado en la automatización de pruebas web para validar flujos críticos de usuario y mejorar la calidad del software.

## 🧪 ¿Qué se automatiza?
- Login de usuario (casos positivos y negativos)
- Validaciones de formularios
- Mensajes de error y estados de la aplicación
- Flujos comunes en aplicaciones web reales

## 🛠 Tecnologías utilizadas
- JavaScript
- Playwright
- Testing automatizado end-to-end (E2E)

## 🧠 Enfoque de calidad
Las pruebas están pensadas desde la perspectiva del usuario final y del negocio, buscando:
- Detección temprana de errores
- Reducción de tareas manuales repetitivas
- Mayor eficiencia operativa en el proceso de testing

## 📁 Estructura del proyecto
tests/  
└─ login.spec.js  
package.json  
README.md  

## 🚀 Cómo ejecutar las pruebas
1. Clonar el repositorio  
   `git clone https://github.com/tu-usuario/qa-web-automation.git`

2. Instalar dependencias  
   `npm install`

3. Ejecutar pruebas  
   `npx playwright test`
