**# qa-web-automation
Web automation tests focused on quality and efficiency**# Web Automation Testing

Repositorio de pruebas automatizadas web enfocadas en validar flujos críticos de usuario y asegurar la calidad del producto.

## 🧪 ¿Qué se automatiza?
- Login de usuario
- Validaciones de formularios
- Flujos positivos y negativos
- Manejo de errores y mensajes de validación

## 🛠 Tecnologías
- JavaScript
- Playwright
- Testing web automatizado

## 🎯 Objetivo
Detectar errores de forma temprana, reducir tareas manuales repetitivas y mejorar la eficiencia operativa del equipo.

## 🚀 Ejecución
1. Clonar repositorio
2. Instalar dependencias  
   `npm install`
3. Ejecutar pruebas  
   `npx playwright test`

## 👩‍💻 Sobre mí
QA en formación con experiencia en soporte técnico y análisis funcional. Interesada en automatización y buenas prácticas de calidad.
