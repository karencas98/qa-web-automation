# Web Automation Testing – QA Portfolio

Este repositorio forma parte de mi portafolio profesional como QA, enfocado en la automatización de pruebas web para validar flujos críticos de usuario y mejorar la calidad del software.

---

## 📌 Contexto del proyecto
El proyecto consiste en la automatización de pruebas web sobre una aplicación real, enfocándose en funcionalidades críticas como el proceso de login.  
El objetivo es asegurar que los flujos principales del usuario funcionen correctamente y detectar errores de forma temprana.

---

## 🧠 Mi análisis
El análisis se realizó desde la perspectiva del usuario final y del negocio, considerando:
- Casos positivos y negativos
- Validación de mensajes de error
- Uso de selectores estables y buenas prácticas de automatización

Se priorizó la automatización de procesos repetitivos para reducir errores humanos y mejorar la eficiencia operativa del proceso de testing.

---

## ✅ Conclusiones principales
- La automatización web permite aumentar la cobertura de pruebas en funcionalidades críticas
- Detectar errores en etapas tempranas reduce retrabajos y riesgos
- Un buen diseño de pruebas facilita el mantenimiento y la escalabilidad

---

## 🚀 Cómo ejecutar las pruebas
1. Clonar el repositorio  
   `git clone https://github.com/karencas98/qa-web-automation.git`

2. Instalar dependencias  
   `npm install`

3. Ejecutar pruebas  
   `npx playwright test`
